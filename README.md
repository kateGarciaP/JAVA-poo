# ☕ Java POO (Programación Orientada a Objetos)

> Proyecto y ejercicios prácticos para afianzar los pilares fundamentales de la Programación Orientada a Objetos en Java, basado en el curso de Platzi.

---

## 📌 Sobre el Proyecto

Este repositorio reúne el código desarrollado para comprender y poner en práctica la modelación de entidades del mundo real en Java mediante el paradigma de Programación Orientada a Objetos (POO).

---

## 🛠️ Tecnologías y Conceptos

* **Lenguaje:** Java Core
* **Paradigma:** Programación Orientada a Objetos (POO)

### **Pilares trabajados:**
1. **Abstracción:** Definición de clases, interfaces y clases abstractas.
2. **Encapsulamiento:** Control de acceso con modificadores (`private`, `public`, `protected`) y métodos getters/setters.
3. **Herencia:** Reutilización de código a través de relaciones entre clases padre e hijo (`extends`).
4. **Polimorfismo:** Sobrescritura (`@Override`) y sobrecarga de métodos para adaptar comportamientos.
